Headings, text styles, lists, checklists, quotes, code, links, images and divider lines.

- Headings in three sizes
- Bold, italic and underline, plus strikethrough and inline code through Markdown shortcuts
- Bulleted lists, numbered lists and checklists, indented up to three levels with the Tab key
- Quotes
- Code blocks with syntax highlighting
- Links: a pasted web address turns into a link by itself
- Images
- Divider lines

The most common ones are in the toolbar. All of them are a few keystrokes away, through the [slash menu](/help/slash-menu) or [Markdown shortcuts](/help/markdown-shortcuts).
